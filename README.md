# 人格偏好探索 · 北欧视觉第二版

原生微信小程序，WXML / WXSS / JavaScript / JSON，无第三方运行依赖，无登录和后端。正式名称待确定。结果仅供偏好探索参考，非 MBTI 官方认证测试、医学诊断或职业能力评定；抽签不预测命运。

## 本版实现

- 测试、抽签、我的三个 Tab；北欧峡湾、白桦、极光与世界树意象，本地无字插画和动态文字分别渲染。
- 160 道情境题、800 个逐题口语化答案，答案不使用“我”。四维各 40，正反各 20。选项具有稳定 ID 与明确分值。
- 24/60 模式、近期题目避让、配额回退提示、上一题、修改、逐题自动保存与恢复。场景不适用可更换同维度同方向的题，题数与配额不变。
- 24 张日常场景插画按题意标签匹配；交替使用独立场景图与卡片头图排版。素材复用，不为每道题生成独立大图。
- 16 型报告；32 张独立人格卡插画，每型两张人物/自然意象卡面；一句性格描述与三个关键词。
- 300 条短句，六类各 50：286 条原创日常短句、14 条古典或国际作者摘句。8 条英文摘句对照原文镜像核查，中文为本项目自译，保留作者、作品、原文和来源 URL。
- 24 张独立抽签卡插画，极光、森林、峡湾、星夜、暖屋、花园六组，各四张。优先匹配签文主题，卡面跨天轮换；轮换记录不随日期重置。
- Canvas 2D 动态绘制 720 × 1200 PNG；卡面切换、相册保存、原生小程序页面分享；历史各最多 30 条，不虚构转发成功。
- 保留旧题库与旧签文文本，旧版未完成测试可按原题及原选项继续；旧历史与旧分享链接不把原签文悄悄换成新文字。

## 导入微信开发者工具

1. 下载 ZIP 并解压到新目录，避免把新文件混入旧项目。
2. 在微信开发者工具中导入项目目录，目录中应直接存在 `app.json` 和 `project.config.json`。
3. `appid` 为明确的测试占位配置 `touristappid`，不是正式 AppID。使用工具支持的测试/无 AppID 模式；若工具不接受此模式，用你自己的测试号 AppID。
4. 建议使用稳定基础库 2.30.0 或以上，需支持 Canvas 2D、素材分包与字体加载。真实分享、预览和发布需要有效 AppID 和账号权限。
5. 没有需要启动的后台服务，也无需 `npm install`。测试需要 Node.js 18+。

```sh
npm test
node tests/check-project.js
```

云任务使用现有检出目录即可，不需要 Git worktree。

## 目录与素材

- `pages/`：10 个交互页面。
- `data/questions.js`：新题库与逐题选项；`profiles.js`：报告和人格卡描述；`fortunes.js`：短句与出处；`share-themes.js`：56 套卡面；`font-source.js`：离线衬线字体子集。
- `assets/nordic/`：三个主视觉、24 张题目场景。统一线条 Tab 图标在 `assets/`。
- `card-art/`：32 张人格图、24 张抽签图，独立素材分包，进入卡片预览时加载；分包页面仅为注册入口。
- `services/quiz-engine.js`：抽题、版本兼容、换题、计分；`card-engine.js`：跨次跨天卡面轮换；`fortune-engine.js`：当天签文防重；`content.js`：旧签文内容兼容。
- `services/poster-renderer.js`：等比裁切、渐变、留白、文本度量、换行与导出；`storage.js`：统一存储。
- `legacy/`：旧版题库与签文文字兼容数据，不能删除。
- `tests/`：自动化检查；`quote-proof.json`：英文摘句来源与原文文件校验信息。

素材来自本次新生成的无字插画，独立画面按图集网格提取并转成 JPEG，不把设计稿文字或控件作为背景。56 张卡面具有不同图像字节，不能只靠换颜色计数。其来源画幅受生成图集分辨率限制；当前海报中文字按 720 × 1200 原生绘制，放大插画仍会有柔化，后续可按相同路径替换为更高分辨率原图。不要把导出尺寸当作插画本身的原生分辨率。

字体为 Noto Serif CJK SC 的离线子集，许可证在 `assets/FONT_LICENSE.txt`。页面标题使用该字体，题目与选项使用系统清晰字体。启动时通过 `wx.loadFontFace` 加载，失败会回退；海报等待加载或超时后继续。不同微信版本对 data URL 字体与 Canvas 的支持须实测，不关闭任何安全校验。主包与素材分包分别检查 2 MiB 保守源文件预算；以微信工具最终打包结果为准。

## 计分、换题与版本

新选项分数为 `−2、−1、0、1、2`，对应方向由各题显式映射。每维按 `sum(选项分数) / (2 × 完成题数) × 100` 归一化；正数倾向 E/S/T/J，负数倾向 I/N/F/P。绝对值小于 15 标为接近均衡。恰好零固定展示该维第一个字母，同时注明不确定性；全中立 ESTJ 是展示规则，不代表确定结论。

24 题每维正反各 3；60 题正向配额 8/7/8/7，反向 7/8/7/8。每四题包含四维。换题仅从相同维度、方向、未出现的题中选择，不将“不适用”算作中立；候选耗尽时说明原因。恢复使用保存的题序、选项 ID 和题库版本。

旧版回答数字与新版选项 ID 都有明确版本解析。旧签文历史默认内容版本 1，新记录和新分享链接明确带版本 2。个人答案与得分不放入共享 URL；收件人无本机记录也能读取通用内容。

## 卡面轮换与本地记录

人格卡从对应类型的两套中随机选择，优先未用卡面、避免连续重复。抽签卡的 24 套全局轮换，优先本轮未用、再匹配签文主题；某主题用完后允许使用其他主题，完整一轮后重开，避开上一张。打开明确指定模板的历史或分享链接会保留该模板，这种主动回看不承诺不重复。

签文防重与卡面轮换分开存储：本地当日最多记录 300 个签文 ID，抽完后可继续；卡面使用记录跨天保留。清空本地数据会一起清除这些记录，换设备也不会云同步。

“我的卡片”保存内容、内容版本和模板 ID，重新打开时重绘，不长期保存临时文件，不表示已经分享。相册中的图片由用户管理，删除历史不会删除相册图片。

## 文案与出处

来源不明的网络名言不硬贴作者名。国际作者引用保留原文与自译标记，避免复制现代版权译文。古典原文也标注作者作品。原创短句明确标为原创；不把引用当作心理测量证据。内容库仍需上线前人工审校语气、出处、适用语境和素材使用范围。
